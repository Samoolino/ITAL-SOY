# ITAL-SOY Repository Population Record

## Baseline

ITAL-SOY was an empty repository at the start of this population stage. The project has now been initialized as the enterprise integration/control-plane repository.

## Methodology inheritance

The current methodology is derived from the VITAL-SOY control-plane construction: QMS, traceability, RBAC, due diligence, automated/verifiable audit logging, HACCP/CCP quality gating, quality-gated backward funding, bounded execution, settlement and verification.

ITAL-SOY is not intended to duplicate the production methodology blindly. It is the integration layer in which the enterprise contract, SaaS access, data containment and institutional deployment model are formalized.

## Population rule

The repository will proceed in this order:

1. Process-flow evaluation.
2. RBAC and data-access verification.
3. Contract-access gateway definition.
4. Verification harness.
5. Contract construction.
6. Unit/invariant testing.
7. Deterministic deployment.
8. Controlled-fork verification.
9. Machine-readable verification report.
10. Production governance approval.
11. Only then: live venue/router adapters.

## Current status

The repository is **architecture-populated**. The process-flow evaluation is the next gate. Institutional contracts are not declared production-ready until their corresponding verification evidence is retained.
